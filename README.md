# CS-210 Portfolio

Portfolio of C++ projects completed for SNHU CS 210.

## Project: Corner Grocer

### Project Summary

For this project, I created a C++ program for the Corner Grocer that tracks how many times each grocery item was purchased throughout the day. The program reads information from a file and allows the user to search for an item, display all item frequencies, or view the information as a histogram. The goal of the project was to use C++ to solve a real-world business problem.

### What I Did Well

I think I did a good job keeping my code organized by separating different tasks into functions. This made the program easier to follow and easier to debug when something wasn't working. I also made sure my output was easy to read and understand.

### Where I Could Improve

If I were to continue working on this project, I would add more input validation to make sure users can't enter invalid menu options or incorrect information. I would also improve the menu so the program is a little more user-friendly. These changes would make the program more reliable and easier to use.

### Challenges and Resources

The most challenging part of this project was learning how to work with maps and read information from a file. At first, it took some trial and error to get everything working correctly. I was able to figure it out by reviewing my course materials, looking back at examples from previous assignments, and testing my code until everything worked the way it should.

### Transferable Skills

This project helped me become more comfortable with C++ and strengthened my problem-solving skills. I also gained more experience with functions, file input and output, maps, and debugging. These are all skills that I can use in future programming classes and projects.

### Maintainability, Readability, and Adaptability

I kept my code organized by using functions for different parts of the program and using variable names that made sense. I also added comments where they were helpful. This makes the program easier to read, update, and build on if I wanted to add more features later.
